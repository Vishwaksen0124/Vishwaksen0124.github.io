# vishwaksen0124.github.io

Personal portfolio of **Vishwaksen Pujala** — Software / AI / Backend Engineer.

🔗 **Live:** https://vishwaksen0124.github.io

## Stack
Hand-coded, dependency-free **HTML / CSS / JavaScript**. No build step — GitHub Pages serves the static files directly.

```
index.html     # markup + content
styles.css     # theme, layout, responsive + dark/light
script.js      # projects/skills data, theme toggle, reveal & counter animations
resume.pdf     # downloadable résumé
```

## Editing
- **Projects** and **skills** are data-driven — edit the `PROJECTS` / `SKILLS` arrays in `script.js`.
- **Experience / About / Contact** are plain HTML in `index.html`.
- Replace `resume.pdf` to update the downloadable résumé.

Push to `main` and GitHub Pages redeploys automatically.
